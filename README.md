# Iconos

Esta carpeta contiene los iconos utilizados en los reportes de **Power BI**.

## Propósito

Centralizar los recursos gráficos para que puedan ser reutilizados en diferentes reportes y dashboards, evitando duplicados y facilitando su mantenimiento.

## Organización

Cada tipo de recurso debe almacenarse en su propia subcarpeta.

**Ejemplo:**

```text
Iconos/
├── README.md
├── Estados/
├── Indicadores/
├── Navegacion/
└── ...
```

## Convenciones

* Utilizar nombres de archivo descriptivos.
* Preferir formato **SVG** cuando sea posible; en caso contrario, usar **PNG**.
* Mantener un estilo visual consistente entre los iconos.
* Evitar caracteres especiales y espacios en los nombres de archivo.

## Uso en Power BI

Los archivos de esta carpeta pueden utilizarse como imágenes dinámicas mediante su URL pública (cuando el repositorio lo permita) o desde el origen de almacenamiento configurado para el proyecto.
